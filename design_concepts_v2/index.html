Six UI alternatives

Each direction moves layout & density, visual style and navigation together — not a re-skin. All six use identical sample data so they're comparable side by side, keep the semantic colour convention (project red / subproject blue / duration green), stay dark-first, and each makes deliberate use of the backdrop-image layer. Frosted glass, terminal chrome, kanban and paper textures are all off the table from round 1.

Round 2 — the original four kept for reference

Command Deck

56px icon rail + ⌘K palette + 44px deckbar · no sidebar

A tool you operate, not a dashboard you visit. Exactly one container treatment and one row treatment — nothing nests, a row is never a card. 4px grid, 13px body, tabular mono numerals with fixed column widths so times align down the whole page. Higher contrast than production because density needs it.

Signature moveThe command palette is the navigation and the timer control. Rail is the mouse fallback.
Dashboardready Projectsready Sessionsnot built

Timeline First

Top segmented control · full width to the timeline

Time is the organising axis, not lists. Sessions are proportional blocks on an hour ruler in per-project lanes; gaps are left genuinely empty; the running timer is a live hatched block bleeding into a NOW line. Colour encodes identity only — every block is a shade of project red, so "red = project" is taken literally.

Signature moveUnworked time isn't grey fill — it's a hole in the UI showing your wallpaper. Every gap in your day is a window.

Ledger Table

40px top bar + sticky subbar · global timer well pinned everywhere

A book of accounts kept in time instead of money. Real <table>s: sticky headers, sortable columns, right-aligned tabular numerals, running totals, bottom summary rule. Two surface tiers only — pane and zebra row. Square corners, hairlines, no shadow, no blur. The 14.5rem the sidebar ate is given back to columns.

Signature moveDensity is the feature — forty things visible at once, with a global timer well so the daily loop never needs a page change.

Focus Card

Floating bottom tabbar → desktop pill · zero width spent on nav

The deliberate opposite: calm, mobile-first, one thing at a time. One question above the fold — "what am I working on right now" — as a giant focus card with one primary Stop button. Everything else progressively disclosed below. Designed at 390px first; desktop is the same layout widened, never a second column.

Signature moveOne primary action per screen. On desktop the narrow column floats in your backdrop photo — the image becomes the room.

State of play

The round-2 workflow hit the monthly agent spend limit partway through, so only 5 of its 12 pages were built — all four dashboards plus Command Deck's Projects. The two round-2b concepts above were then built directly, without agents.

  • Every concept's concept.css is complete. The design systems are fully specified; only extra page mockups are missing.
  • Deck + Timeline reuses Command Deck's stylesheet verbatim and appends the timeline, so the session rows are byte-identical to what you saw.
  • Focus Desk reuses Focus Card's stylesheet and appends a desktop layer — the phone layout is untouched.
  • Known, pre-existing: Command Deck's .runbadge and .row-actions overflow horizontally below ~430px. That came from the original concept, not the timeline splice, and it's inherited by Deck + Timeline.
