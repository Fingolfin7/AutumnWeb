{% comment %} ============================================================================ OPTION PICKER — the one shape every multi-select filter wears. ---------------------------------------------------------------------------- A checkbox set only stays readable while it is short. Tags are short; "exclude projects" is however many projects the user has ever made, and as a bare grid of checkboxes it made the filter sheet several screens tall. So the options live in a bounded, scrollable well: chips instead of rows, an optional search field pinned to the top of the well, checked chips pinned to the front of the list, and a count beside the label. The sheet is then the same height whether the user has six projects or six hundred. option_pickers.js drives search / pinning / count off `data-picker`.
